📱 Catalog App (Flutter + Dart)

 My first project in Flutter & Dart — a simple yet elegant Catalog App that showcases products with clean UI, smooth navigation, and modular code structure.

✨ Features

  🏗️ Built with Flutter Widgets

  📂 Handles data from JSON (catalog.json)

  🎨 Clean coding practices: modular structure, reusable widgets, and readable code

  🛒 Add-to-cart functionality

  🖼️ Hero animations & smooth navigation transitions

  📱 Responsive layout for different devices

  🚀 Scalable code for future enhancements


🛠️ Tech Stack

Dart

Flutter

VelocityX  (for UI utilities)
 

🚀 Getting Started

Clone the repo

  git clone https://github.com/your-username/catalog-app.git
  cd catalog-app


Get dependencies

  flutter pub get


Run the app

  flutter run
